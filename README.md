# PersonalEricMbida organization defaults

Shared guidelines for projects in the ericmbida.com Enterprise.

- [Organization profile](profile/README.md)
- [Contributing](CONTRIBUTING.md)
- [Security reporting](SECURITY.md)
- [Support](SUPPORT.md)
- [Code of conduct](CODE_OF_CONDUCT.md)

Repository-specific policies override inherited defaults. Maintainers should keep their repository README, installation, operations, and recovery instructions current. Never publish credentials or sensitive infrastructure details.

Organization members can consult the private enterprise-governance repository for operating standards and use repo-template to start new projects.
