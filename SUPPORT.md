# Support

Start with the repository README, installation guide, troubleshooting notes, and existing issues.

For ordinary bugs or questions, open a repository issue with the relevant version, environment, expected behavior, actual behavior, and sanitized logs. Use the documentation issue form for unclear or missing instructions.

For vulnerabilities or credential exposure, follow SECURITY.md. Never include passwords, tokens, personal data, or internal infrastructure exports in public reports.

These are personal learning and portfolio projects. Support is provided as time permits, with no service-level or availability commitment.
