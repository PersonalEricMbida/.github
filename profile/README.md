## Engineering approach

> If I build it, I document it.
> If I repeat it, I automate it.
> If I expose it, I secure it.
> If I depend on it, I back it up.

Projects should be practical, reproducible, and maintainable. Public repositories contain sanitized examples; sensitive operational material belongs in restricted repositories.
