# Code of conduct

Be respectful, constructive, and considerate of different backgrounds and experience levels. Critique ideas and code rather than people. Give useful context, credit others' work, and respect privacy.

Harassment, threats, discriminatory abuse, sexual harassment, doxxing, and knowingly publishing another person's confidential information are unacceptable in project spaces.

Report concerns to the repository owner through an existing trusted private channel. If no channel is available, request one without publishing details about the people involved. The owner should handle reports discreetly and disclose details only as needed to investigate and respond.

Maintainers may edit or remove inappropriate contributions and restrict participation proportionately to the behavior. A person involved in a report should not investigate their own conduct; seek an uninvolved trusted maintainer where available. These personal projects do not promise a formal investigation service or response deadline.
